Hello, and welcome! 👋

I finally set up a place to write things down. For a while my notes, half-finished
ideas, and "I should really remember how I did that" moments lived in scattered
text files. This blog is my attempt to put a few of them somewhere public.

## What this is built with

This site runs on [Astro](https://astro.build), a framework built for fast,
content-heavy sites. Pages are plain HTML by default — no JavaScript shipped
unless a page actually needs it — so it loads quickly and stays simple.

A few things I wired up from the start:

- **Markdown posts** — every file in `src/content/blog` becomes a page.
- **Tags** — each post can be filed under a few topics.
- **Dark mode** — toggle it with the button up in the corner.
- **RSS + sitemap** — so the site plays nicely with readers and search engines.

## What I'll write about

Mostly the things I'm building and learning. Some posts will be quick notes,
others longer write-ups. No fixed schedule — just whenever I have something
worth sharing.

Thanks for reading. More soon.
